# Oddfield Productions

**Something worth gathering for.**

Oddfield Productions is an independent event and creative production company rooted in the Rio Grande Valley, Texas. The website introduces event production services, original experience formats, collaborative opportunities, and practical event feasibility planning.

**Website:** [oddfieldproductions.com](https://oddfieldproductions.com/)

## Features

- Responsive single-page design with original Oddfield branding, sigil, and editorial photography
- Streamlined navigation with **Plan an Event** and **Feasibility Check** pathways
- Experiences, production capabilities, working approach, and collaboration opportunities
- Interactive **Whiteboard** for ticket revenue, vendor income, costs, contribution margin, and break-even scenarios
- Optional ability to include a Whiteboard scenario in an event inquiry
- Compact native-styled inquiry form with optional project details and inline submission feedback
- Formspark submission handling with validation, honeypot protection, and duplicate-submission prevention
- Search, Open Graph, Twitter, and structured business metadata
- Custom-domain configuration for `oddfieldproductions.com`

## Built With

- HTML, CSS, and JavaScript
- Bootstrap 5, adapted from the BootstrapMade Horizon template
- Formspark for event inquiries
- GitHub Pages for static hosting

The site is designed to stay lightweight, easy to maintain, and expandable as real events are announced.

## Deployment Notes

- Keep `index.html`, `CNAME`, and `README.md` in the repository root, with CSS at `assets/css/main.css`.
- Retain the Horizon `assets/vendor/` libraries and `assets/js/main.js`, plus the images in `assets/img/` (`logo.png`, `logoLight.png`, `signature.png`, `hero.png`, `festival.png`, `music.png`, `culture.png`, `production.png`, `contact.png`, and `social.png`).
